Instalacija

Kako se uređaj priključi na ovaj folder.

1

Preuzmi shf

curl -fsSL https://shared-storage.igor.digitalcube.work/gui/install.sh | sh
2

Pridruži se folderu

Token dobijaš od admina (strana Članovi i tokeni). Svaki uređaj treba svog člana.

shf join https://shared-storage.igor.digitalcube.work \
    493b54d3-e884-47ef-b8b1-af062f1a3adb shf_… ~/projekti
3

Pokreni kao servis

shf service install
shf status            # state: synced
4
Ako shf status pokazuje key refused, isti član je pridružen sa drugog uređaja. Napravi novog člana za ovaj uređaj.
